# S.A.C. — Two Art Direction Studies

Standalone, no-dependencies, no-build HTML/CSS/JS creative prototypes. No repository changes, no Netlify changes.

## How to view

Open `compare.html` in any modern browser, then explore `forest.html` and `desert.html`. If desired, run `python -m http.server 5500` from this folder. No npm or Git required.

## Directions

- **01 Forest × Coral / Studio Expression** — deep forest green and signal coral, room/architecture-first opening, bold editorial handoff.
- **02 Desert × Cobalt / Architectural Energy** — warm clay architecture framing electric blue skies, cobalt-blue editorial handoff.

Both sites use the same information architecture for direct comparison: a pinned, aperture-expansion scroll opening; connected typography reveal; studio editorial; horizontal photographic gallery; company systems; interactive illustrative material-colour study; verified company information; contact and external Product Studio CTA.

## Tech

- Responsive layout and typography, no remote fonts or libraries
- Viewport-sticky hero sequence with scroll-synchronised mask and camera movement
- Ambient drifting movement without scroll
- A single continuous handoff to colour field; no forced-scroll hijacking
- Horizontal, scroll-controlled architectural photo essay
- Contextual reveal, functional navigation and colour study buttons
- Reduced-motion styles and accessible native links/buttons

**Not full volumetric 3D or bespoke photographic film.** Further improvement requires a purpose-built visual sequence with controlled camera/object positions and licensed source material. Photographic perspective cannot change volumetrically from a single still image.
