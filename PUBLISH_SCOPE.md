# 3Knights publication scope

This repository contains the approved Forest, Desert and Neutral creative previews and their Material Library pages.

Only static website files are to be committed: HTML, CSS, JavaScript and image assets.

No GitHub Actions workflows, no custom token permissions, no third-party services, and no deployment automation are included. GitHub Pages will be configured separately using Settings > Pages > Deploy from a branch.

The source images and material swatches are design-study content; verify rights and product accuracy before official/commercial use.
